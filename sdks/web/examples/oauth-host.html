Host auth resolver registration

This example loads the real WASM module and registers a host callback. An OAuth client belongs in the host application. Replace the callback below with a lease from that client's token store.

Using this callback for a session requires a custom Rust/WASM bootstrap with an ExternalResolver { handle: "wasm_host" } binding. Stock MeerkatRuntime.init() accepts provider keys and proxy URLs, and does not install custom realm bindings. This registration demo performs no OAuth login or provider request.

Build sdks/web, serve it over HTTP, and open this page.

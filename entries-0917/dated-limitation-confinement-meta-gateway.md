- Added 2026-11-17, after the release. Confinement under a Meta gateway: `meta_gateway` and `rpc_gateway` do not apply the `[confinement]` table, and have no argument, init parameter or host hook that selects a confinement, for anything they launch for a member. A member's shell commands, command hooks, local MCP stdio servers and stdio skill sources run as unconfined processes of the gateway's OS user and can write what that user can; the table can be present in the members' configuration and changes nothing for them: the gateway reads and parses it (an unknown mode is refused at init) and then starts without a word about it. A host binary built over the stdio gateway (Connect's among them) has no way to select one either: it can refuse a member's local MCP stdio server before it starts and can put its own review in front of the members' operations; neither confines a process that has started. The same holds for a Rust program that runs Meta's own library runtime, which builds the members' factory itself; only a program that builds its own Core factory and hands Meta a session service made from it can set a confinement itself. The configuration reference of Meta 0.9.9 through 0.9.15 said that `[confinement]` applies to every member; that was not so, and the published page no longer says it. Besides such a review (which operations it covers under a gateway was not read), what can judge a member's shell command under a gateway is the `[shell]` section's own command rules: their default mode is unrestricted, so by default they judge nothing, and where they are set they judge the command's text, not what a started process may write. Do not rely on `[confinement]` for the members of a Meta gateway. Affected: Meta 0.9.9 through 0.9.16; earlier Meta releases were not read. (Shown by a run of the published `rpc_gateway` 0.9.16 on Linux x86_64: with `[confinement.all]` `mode = "workspace"` in the members' configuration a member's shell command wrote a file outside the gateway's directory, and nothing in the gateway's output named confinement. `meta_gateway`, command hooks, MCP stdio servers, skill sources and the earlier releases: read from the source at the release tags, where no line of Meta's or Connect's crates selects a confinement; not run.) No fix is scheduled yet.

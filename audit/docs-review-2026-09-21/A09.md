## A09-001: Remove the claim that inherited image generation is hidden in normal runtime composites

**Candidate severity:** medium. **Independent verdict:** confirm.

The paragraph tells CLI/REST/RPC users that the inherited category is hidden, although a normal composite exposes it when the machine, executor, planner and blob store are present. It also contradicts the later correct image-generation description on this same page. This misstates the default tool exposure and sends users looking for an enable switch that is not required on the normal path.

## A07-001: run_completed usage excludes that run's later extraction and is not always the final RunResult usage

**Candidate severity:** high. **Independent verdict:** confirm.

For structured-output runs, the latest run_completed event is a pre-extraction snapshot. The eventual successful RunResult includes measured extraction calls and retries, so the documented equivalence and extraction row undercount the final session cost. Differencing successive RunCompleted snapshots also shifts the previous run's extraction into the next interval instead of measuring complete logical runs.

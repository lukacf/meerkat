Meerkat Connect lets agents find, configure and use integrations. Describe the work you need done; the setup agent selects the software, prepares its configuration and brings the required installation and access decisions to you.

Connect includes more than 100 service integrations and can research Python, Node and MCP packages beyond its library. Use it from the terminal, embed setup in your application's Console, or use its SDKs directly.

## Start with the work

Ask for an outcome: "Read last week's updates from these Slack channels and draft a summary for the team." The agent works out which integrations and operations the task needs. You review the selected software, account and access before it is used.

In the **CLI**, choose a realm, complete setup, then use the integration through an ordinary `rkat` agent in that realm. In an **integrated Console**, the application presents setup alongside the original conversation and manages the return to that task.

## Control the access

An installation, an account connection and an agent's permissions are separate choices. You can use the same service with several accounts, give an agent selected operations, and set an access lifetime. Credentials go through protected terminal or application controls, outside the agent conversation.

Connect builds on Meerkat's runtime and Meta's application framework. Its Python and TypeScript service libraries are also usable independently. See [platforms and installation options](/availability) to choose your starting point.

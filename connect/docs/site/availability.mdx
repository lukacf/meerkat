Connect 0.9.14 works with Meerkat Core and Meta 0.9.14. Download archives, SDKs and checksums from the [release page](https://github.com/lukacf/meerkat/releases/tag/connect-v0.9.14).

<Note>
The commands on this page and in the quickstart select released 0.9.14 artifacts.
Connect 0.9.10 does not support in-place updates that change an application's
tool policy, definition, instructions or runtime; Forge's Stage refuses them,
so keep the existing installation and state. Shared multi-caller setup is an
unqualified opt-in, available only when an application starts the gateway with
`--private-workflow-launch`; ordinary CLI and Console setup stay single-caller.
</Note>

## Platforms

| Platform | Requirements |
| --- | --- |
| macOS | Apple Silicon, macOS 13.5 or later |
| Linux | x86_64, glibc 2.39 |

The 0.9.14 release has complete archives for Linux x86_64 only. No complete
Apple Silicon macOS archive is published in this release.

The release workflow also builds the `meerkat-connect` and `toolkit_gateway`
executables for Apple Silicon macOS and adds them to a release as
`meerkat-connect-<version>-aarch64-apple-darwin.tar.gz` and
`meerkat-connect-gateway-<version>-aarch64-apple-darwin.tar.gz`, each holding
one executable, with a `.sha256` file beside it. Check a release's asset list
for them. They are not a complete installation: they carry no Python,
Node/npm, integration library or setup resources, and an executable built
without them refuses every step that needs them. The interactive
`meerkat-connect` setup conversation stops at startup, and no integration can
be prepared, installed or read back; gateway startup for an application
whose setup supplies no bundled helper reads no bundled resource. Intel macOS
is not built.

The CLI archives include Python, Node/npm, the integration library and setup resources. Extract and retain the complete directory, including executable permissions and `libexec` contents.

## Choose an installation

| Use | Install | Next step |
| --- | --- | --- |
| Set up services from a terminal | Complete Connect CLI archive and Meerkat Core | [Quickstart](/quickstart) |
| Add setup to your application | Connect gateway, matching Meta SDK and Connect host components | [Host composition](/guides/host-composition) |
| Call service operations from Python | `meerkat-toolkit` wheel and selected extras | [Python SDK](/sdks/python) |
| Call service operations from TypeScript | `@rkat/toolkit` package | [TypeScript SDK](/sdks/typescript) |
| Render connection management | `@rkat/toolkit/ui` browser entrypoint | [Management UI](/sdks/ui) |

SDK packages are distributed as GitHub release assets. The SDK guides include direct installation commands.

## Integration profiles

Each profile identifies its operations, account inputs and configuration. The library contains 101 integrations on macOS and 100 on Linux. The browser automation profile is available on macOS.

Use the [integration library](/library/adoption) to explore services. For a package beyond the library, follow [agent-led discovery and installation](/concepts/acquisition).

## Application integration

An integrated Console uses your application's login, original conversation and runtime lifecycle. Frontends such as Slack or Telegram additionally use the application's participant, routing and delivery policies. See [frontend setup](/guides/setup-a-frontend).

## Distribution

Keep the bundled licenses and notices with redistributed software. Package metadata records the source and license information for each integration.

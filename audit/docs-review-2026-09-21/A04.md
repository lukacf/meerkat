## A04-004: The per-tool timeout TOML example uses a representation its Serde field does not accept

**Candidate severity:** medium. **Independent verdict:** confirm.

The block is valid TOML syntax but shell = "2m" cannot deserialize as the map's standard Duration. Copying the common tool-gates example can prevent the whole configuration from loading.

### Baseline documentation evidence

- [docs/cli/configuration.mdx:110-115](https://github.com/lukacf/meerkat/blob/56208b9e6cee078f52c43af8f6b36660bc93eeb4/docs/cli/configuration.mdx?plain=1#L110-L115)


### Implementation proof

- [meerkat-core/src/config.rs:2361-2376](https://github.com/lukacf/meerkat/blob/56208b9e6cee078f52c43af8f6b36660bc93eeb4/meerkat-core/src/config.rs#L2361-L2376)

  ToolsConfig derives Deserialize and this map has only #[serde(default)]. Its values therefore use the ordinary std::time::Duration Serde representation, not humantime strings.

- [meerkat-core/src/config.rs:2368-2374](https://github.com/lukacf/meerkat/blob/56208b9e6cee078f52c43af8f6b36660bc93eeb4/meerkat-core/src/config.rs#L2368-L2374)

### Independent challenge

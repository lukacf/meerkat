### C02: The sentiment confidence schema does not enforce its advertised 0–1 range

**Independent challenge:** The declared domain is confidence between 0 and 1, but the exact schema emitted by the real example contains only type:number and a description. **Severity:** medium. **Verdict:** confirmed. **Examples:** 003, 008, 023, 027.

**Original proof:** Used an executable Python JSONL child as MEERKAT_BIN_PATH. It loops over stdin, and answers initialize with {"jsonrpc":"2.0","id":request.id,"result":{"contract_version":"99.0.0","methods":[]}}, then remains waiting on stdin. For each of 003, 008, 023 and 027, ran node --import ./examples/node_modules/tsx/dist/loader.mjs examples/<directory>/main.ts via subprocess.run(capture_output=True, timeout=2). Every entrypoint printed the VERSION_MISMATCH/incompatible error before timing out; none exited voluntarily. The parent killed each bounded test process, which closed the mock child's stdin. Static control flow proves client.close() is unreachable on this rejection. The equivalent Python examples exited 1, so this reported hang is deliberately limited to TypeScript.

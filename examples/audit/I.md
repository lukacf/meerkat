**Original proof:** node ../../../../.copilot/session-state/eb71fac5-cb92-4b10-b39f-8d79f3799312/files/audit-I-browser-repro.cjs executes the actual app.js with synthetic DOM/media/fetch. Cleanup must be idempotent, retain the channel ID needed for close, detach old callbacks, stop all owned tracks, close peer/data channel, stop owned timers/meter, and prevent a stale attempt from replacing a newer attempt's state. Apply exception-safe ownership to both smoke entrypoints: explicit remote close in an inner cleanup path and browser.close in an outer finally. Share I06's bounded/cancellable cleanup instead of adding a second lifecycle.

### I04: Interrupted spoken transcripts contaminate the next streaming answer

**Severity:** medium. **Verdict:** confirmed. **Examples:** 037.

**Original proof:** node ../../../../.copilot/session-state/eb71fac5-cb92-4b10-b39f-8d79f3799312/files/audit-I-browser-repro.cjs feeds old spoken delta 'obsolete ', interrupt(old), a new user transcript, and new spoken delta 'fresh'. The displayed new draft becomes 'obsolete fresh'. Supplying the new response's normal transcript-final repairs that new row to 'fresh', but the old interrupted row remains draft=true indefinitely. The finding does not claim the normal final necessarily retains the wrong prefix.

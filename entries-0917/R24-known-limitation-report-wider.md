- The new report of an unsettled run (see Added, "A session whose committed run never settles is reported by name") can say more than is true. The check `session_run_settlement` and the mob's error line ("member's committed run is not settled; the member starts nothing further until it is") count every run whose completion is not yet settled, also a run that failed or was cancelled. That is exact for a run that completed. After a run that failed or was cancelled the session does take and start later runs while that completion is unsettled, so `degraded`, or that line, can stand for a member that is working. Read from the source; not run. The line's wording is to be corrected in a later release.

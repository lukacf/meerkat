- OpenAI `gpt-6.2-astra` (GPT-6.2 Astra) and `gpt-6.2-sol` (GPT-6.2 Sol), available on OpenAI's API by 2026-11-17, are cataloged as Supported OpenAI models: a 1,050,000-token context window with a separate 922,000-token input ceiling, 128,000 output tokens, text and image input, text output, and the reasoning effort levels `low`, `medium`, `high`, `xhigh` and `max`. A request that names `none` or `minimal` for one of them is refused before the provider is asked, as for every level a catalog row does not list; OpenAI refuses both levels for the two models. A request that names no level is answered by the provider at `medium`. Neither is a realtime model: OpenAI lists the Realtime endpoint as not supported for them, so they are not cataloged for live sessions. No default, alias or example changes: the OpenAI default stays `gpt-6-astra`. The rest of the two rows (web search, structured output, images in tool results, a system message after the first turn, a forced tool choice, the GPT-6 Responses prompt-cache defaults and a 600 s call timeout) is that of `gpt-6.1-sol`'s row. A configuration that already defines one of the two ids itself must drop that entry (see Upgrade notes). (The limits, the modalities and the endpoints are from OpenAI's model pages as read on 2026-11-17. Shown by calls to OpenAI's Responses API on that day: on both models the five levels were accepted and `none` and `minimal` refused with HTTP 400, a call without a level came back at `medium`, and an image input and a system message after an assistant turn were accepted. Shown by runs of both models through an `rkat-rpc` built from the source of this release's catalog change: a plain turn, a tool call, a structured output with a schema, an image input, an image in a tool result, each of the five levels sent as asked, `none` and `minimal` refused by Meerkat itself with `-32602` (`reasoning_effort_refused`, `unsupported_level`, naming the supported levels), and a second turn that followed a system prompt given with that turn. Not run: web search, a forced tool choice and the prompt-cache lifetimes.)

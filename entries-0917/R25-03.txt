- A persistent `meta_gateway` with no mob definition file: the upgrade itself needs no step: the gateway takes the mob id its state directory records, and the `definition.json` of the 0.9.16 step may stay or be removed, but keep it if you may go back to a release other than the one that created the state directory (shown by rows on state that the tests write in the form 0.9.15 and 0.9.16 wrote; on state written by a published gateway: read from the source). Check the launch before the first start on this release. On a state directory that holds a mob such a launch is now served whatever its other inputs are (but for the one refusal named under Breaking: a project root in or under the state directory, the gateway home or the provider credentials root), where a launch whose workspace path, realm, `auth_config` or configuration files differed from those the mob was created under was refused. A state directory created under a sign-in configuration and started without `auth_config` is served on a Console that identifies nobody: make sure the launch carries the `auth_config` its Console needs and that `store_path` names the state directory you mean. A start is still refused, now with `-32019` on the request's `id`, where the composition file beside a mob's storage cannot be read, or was removed and the launch does not come to the mob id the storage holds (a mob that this release created under the same launch is adopted again without a refusal), and where the mob was created from a definition file that differs from the built-in default and the launch has none. Going back: a state directory that an earlier release created starts on that release as before, with the same launch, as far as this change goes; a 0.9.16 or earlier gateway refuses a default mob that another release created, this one included, unless the workspace holds its definition as a file: copy the `definition` object from `<state directory>/event_log.sqlite3.composition.json` to `<workspace>/definition.json` first (the 0.9.16 upgrade step, described under Meta 0.9.16 in the upgrade guide; for a mob created by this release: read from the source, not run).

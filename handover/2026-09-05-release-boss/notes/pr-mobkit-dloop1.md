MobKit side of meerkat #1102 (the OB3 fleet-wide delivery stall), part 1: everything that compiles against the pinned meerkat 0.8.33. Part 2 (typed `MemberReloadRequired`, bounded submits, the meerkat-mob reload primitive) follows after the 0.8.34 repin.

- **Circuit breaker keyed on the open actor-loop stall.** New `actor_loop_health` (`Live | Stalled { stall_id } | Terminated`, a tokio watch) owned by the unified runtime, written by the probe, observed by the identity-first bridge. While a stall is open, deliveries fail immediately with typed `ActorLoopStalled { operation, identity, stall_id, stalled_for }` instead of waiting the 600 s admission budget; a stall opening mid-wait cuts the wait; recovery reopens the path. WARN per refusal with the stall id and elapsed time.
- **Probe semantics.** `ActorCommandChannelClosed` / `ActorReplyChannelClosed` on the probe mean the actor terminated: new `ErrorEvent::ActorLoopTerminated`, ERROR log naming the restart, health marked terminated, never `actor_loop_recovered`. SDK error-category mirrors updated (Python + TS parity green).
- **`mobkit/member_health`** (console + RPC): lifecycle state, bootstrap state, materialization in flight, session id, generation, last delivery error, actor-loop health and open stall id; `durability` reserved for 0.8.34.
- **`mobkit/reload_member`** (console + RPC + Python + TS): non-destructive, same session id and same continuity generation. Retire with memory hooks skipped, explicit `Retiring -> Dormant`, re-embody the recorded session under one lifecycle lock; returns `{ reloaded, disposition, session_id, generation }`. `respawn_member` (destructive continuity reset) is never called. Note: on 0.8.31 "retire_member then send" does not re-materialize (nothing moved `Retiring` to `Dormant`); this verb is the fix.
- **Typed reload-required classification.** Repair-blocked / cold-reload-required admission errors classify as typed `ReloadRequired`, routed to exactly one automatic `reload_member` attempt per delivery, then typed failure; never the repair path, never a bare string.

Tests: 82 + 192 targeted Rust tests, console happy path, Python 176, TypeScript 729; clippy clean; pre-push gate passed on the release VM. Docs and CHANGELOG updated. Refs lukacf/meerkat#1102.

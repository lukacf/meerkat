- Cancellation on a custom Rust host: an interruption during a write through the native runtime-store adapter could leave later store calls for that session refused until the store was reopened. In the tested case a cancelled run continued after the store reopened, made another model request and consumed its input. With the correction, cancellation completed, the run ended cancelled, and the session ran its next prompt in the same process. The original transcript was not examined; neither a tool effect nor data loss was established. By source review, the built-in SQLite and in-memory stores do not use this adapter. The affected write form was found at the 0.9.5 through 0.9.16 tags; the interruption was not tested on those releases.

---
title: "Integration workflow"
description: "Follow an integration from a request through setup and use."
icon: "route"
---

Connect separates the agent's choice of integration from the software and access decisions that make it usable.

<Steps>
  <Step title="Describe the task">
    Include the resources, account, audience and result you need. See [request an integration](/guides/request-an-integration).
  </Step>
  <Step title="Choose the integration">
    The agent inspects the [library](/library/adoption) or [researches a package](/concepts/acquisition), then selects its operations and configuration.
  </Step>
  <Step title="Review software and access">
    Review the installation, service account, agent, permitted operations and access duration. Enter credentials through the protected controls.
  </Step>
  <Step title="Use the connection">
    In the CLI, start an ordinary agent in the same realm. In an integrated application, follow the original task's continuation.
  </Step>
  <Step title="Manage access">
    Return to Connect to change credentials, reconnect an account or change agent access. See [connection management](/guides/manage-connections).
  </Step>
</Steps>
